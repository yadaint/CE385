## ข้อ 3: จัดการ Array ด้วย map filter reduce
- map คือ การหยิบมาตามที่เรากำหนด เช่น .map(s => s.name) ก็หยิบมาแค่ชื่อ

- filter คือ การคัดตามเงื่อนไขที่เรากำหนด เช่น filter(s => s.score >= 50) คือการกำหนดว่าคะแนนต้อง 50 ขึ้นไป

- reduce คิอ การรวบข้อมูลให้หลือค่าเดียว 

- หลักการทำงานของ acc[grade] = (acc[grade] || 0) + 1
1 ตรวจสอบว่าในออปเจคมีคีย์ของเกรดหรือยัง เชน A
2 ถ้าเจอคนแรก คต่าจะยังเป็นค่าบังคับโดยเริ่มที่ 0 แล้วค่อยบวก 1
  - ถ้าได้ A คนเดียว ผลจะเป็น A : 1
  - ถ้าไม่มีใครได้ A ผลจะไม่ขึ้นค่า A เลย

- การต่อท่อ คือการนำ map filter reduce มาต่อรวมเป็นคอมโบเดียวได้เลย ทำให้จบได้ในชุดเดียว แบบไม่ต้องสร้างตัวแปรเพิ่ม
