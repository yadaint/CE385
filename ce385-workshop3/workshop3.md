 ## สรุป workshop 3

 ## ข้อ 1 Error-First Callback
 เป็นการโยนฟังก์ชันไปให้คนอื่นเรียกใช้เมื่อทำงานเสร็จ กฎเหล็กของ Node.js คือ "ช่องแรกต้องเผื่อไว้ให้ Error เสมอ" (err, data)

- ต้องเช็คพังก่อนเสมอ ก่อนจะเอา data ไปใช้ ต้องเขียน if (error) เพื่อเช็คก่อนว่ามีปัญหาไหม

- อย่าลืมเบรกโค้ด ถ้าเจอ error ต้องใช้คำสั่ง return callback(err) เพื่อหยุดการทำงาน 
ไม่งั้นโค้ดจะรันทะลุไปบรรทัดล่างจนพัง

- เวลาเขียนฟังก์ชันซ้อนกัน (เช่นใน .find(s => ... )) ระวังอย่าไปเรียกชื่อตัวแปรผิด scope ให้ใช้ตัวแปรที่รับมาในฟังก์ชันย่อยนั้นๆ

## ข้อที่ 2 แปลง Callback เป็น Promise
แก้ปัญหา Callback ซ้อนกันจนอ่านยาก โดยเปลี่ยนมาเป็น "ใบจอง" (Promise)

- ทำงานเสร็จ เรียก resolve(ข้อมูล)
- มีปัญหา/พัง เรียก reject(ข้อผิดพลาด)

then() (โซนผ่าน)
ถ้าทำงานผ่าน ดึงข้อมูลสำเร็จ โค้ดจะวิ่งมาทำตรงนี้

.catch() (โซนพัง)
ถ้างานมีปัญหา เกิด Error มันจะข้าม .then() แล้วกระโดดมาตรงนี้แทน

.finally() (โซนปิดท้าย)
ไม่ว่าจะผ่านหรือพัง ตอนจบยังไงก็ต้องแวะมาทำตรงนี้เสมอ

การต่อโซ่ (Promise Chaining)
เราสามารถใช้ .then() ต่อกันได้เรื่อยๆ แต่ข้อสำคัญคือ "ต้อง return ค่าเสมอ" 
เพื่อส่งไม้ต่อให้ .then() ชั้นถัดไป

Promisify คืออะไร? มันคือวิชาแปลงร่างฟังก์ชัน Callback รุ่นเก่า ให้กลายเป็น Promise รุ่นใหม่ เพื่อให้เขียนโค้ดง่ายขึ้น

##  ข้อที่ 3 async/await และลำดับ vs ขนาน
เปรียบเทียบความเร็ว ดึงข้อมูล 3 คน (คนละ 300ms)

Sequential (ทำทีละคิว) ใช้ for...of + await
- การทำงาน: รอคนแรกเสร็จ -> ค่อยดึงคนสอง -> ค่อยดึงคนสาม ใช้ 900ms ช้าเพราะรอคิวทีละคน

Parallel (ทำพร้อมกัน) ใช้ Promise.all + map
- สั่งดึงข้อมูล 3 คนพร้อมกันรวดเดียว ใช้ 300ms ไวกว่า 3 เท่า

## ข้อที่ 4 เลือก Combinator ให้ถูกงาน
- Promise.all ต้องรอดครบทุกอัน ถ้ามีอันไหนพังแค่อันเดียว ถือว่าพังทั้งหมด 

- Promise.allSettled ต้องการรู้ผลของทุกอัน ทั้งอันที่ผ่านและอันที่พัง โดยไม่ให้ตัวที่พังมาฉุดตัวอื่น 
ไม่สนใจว่าจะสำเร็จหรือล้มเหลว รอจนครบทุกอันแล้วรายงานผลว่าอันไหนรอด อันไหนไม่รอด

- Promise.any เอาตัวที่สำเร็จตัวแรกเท่านั้น ตัวไหนพังก็มองข้ามไป เอาตัวที่ดึงข้อมูลเสร็จไวที่สุดและ 
ไม่พัง มาใช้งาน

- Promise.race ใครถึงเส้นชัยก่อน ชนะ (แม้จะพังก็ตาม) แข่งกันเลย ถ้าครบเวลา Timeout ก่อนดึงข้อมูลเสร็จ ตัว Timeout จะชนะและสั่งตัดจบทันที (ใช้แคชเก่าแทน)
