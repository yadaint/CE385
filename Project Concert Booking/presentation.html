WEB APPLICATION PROJECT · CE385

BOOKING TICKET CONCERT

ระบบจองตั๋วคอนเสิร์ตออนไลน์ — เลือกโซน เลือกที่นั่ง ชำระเงินผ่านสลิป รับบัตร QR รายที่นั่ง
พร้อมหลังบ้านแยกระบบล็อกอินแอดมิน บันทึกเวร และบันทึกรหัสผู้ตรวจทุกรายการ

React + TypeScript · Express + Prisma + PostgreSQL · Tailwind CSS · i18n (ไทย/EN)

OVERVIEW

ภาพรวมโปรเจกต์

🎯 โจทย์

การจองบัตรคอนเสิร์ตแบบเดิมมีข้อจำกัดเรื่องผังที่นั่ง คิวยาว การยืนยันการชำระเงินไม่ชัดเจน ไม่รู้ว่าใครตรวจสลิป และไม่รู้สถานะบัตรแบบเรียลไทม์

💡 โซลูชัน

เว็บแอปจองตั๋วครบวงจร — ผู้ใช้เลือกผังโซนและที่นั่งเอง โอนเงินแนบสลิป แอดมินอนุมัติพร้อมบันทึกรหัสผู้ตรวจ จองสำเร็จได้บัตร QR + พิมพ์ใบเสร็จ

🎫 ผลลัพธ์

บัตรเข้างานรวมรหัสตั๋วทุกในบนบัตรเดียว + QR, ราคาแยก VAT 7%, หลังบ้านแยกระบบล็อกอินแอดมินพร้อมระบบเวรประจำวัน และรองรับสองภาษา

ทุกสถานที่ใช้ผังมาตรฐานเดียวกัน (Standard End Stage): Standing ชิดเวที → VIP → Platinum → Gold → Silver → Balcony

USER FEATURES

ฟีเจอร์สำหรับผู้ใช้

สมัครสมาชิก + ยืนยันตัวตน

ชื่อ-นามสกุล · วันเกิด · เบอร์โทร · เลขบัตรประชาชน 13 หลัก (ตรวจ checksum) · เลขหลังบัตร (Laser code) — ตรวจทั้ง client และ server

ผังโซนวงแหวนรอบเวที

Standing ชิดเวทีสุด → VIP → Platinum → Gold → Silver → Balcony พร้อม % การจองรายโซน

เลือกที่นั่งรายตัว

สถานะทุกที่นั่งเรียลไทม์: ว่าง / รอตรวจสอบ / ยืนยันแล้ว — จองได้สูงสุด 4 ที่นั่งต่อรอบ

ชำระเงิน + นับถอยหลัง

โอนเข้าบัญชีกสิกรไทย นับถอยหลัง 10 นาที แนบสลิปรอแอดมินตรวจ — แสดงยอดก่อน VAT / VAT 7% / ยอดรวม

บัตรรวมทุกรหัส + QR + ใบเสร็จ

บัตรใบเดียวรวมรหัสตั๋วทุกที่นั่งเรียงแนวนอน (มีเลขที่นั่งในวงเล็บเมื่อซื้อหลายใบ) · QR มีรหัสครบทุกใน · ปุ่มพิมพ์ใบเสร็จรับเงินแยก VAT

สองภาษา + ลบบัญชีแบบมีเงื่อนไข

ไทย/English สลับได้ทันที · ลบบัญชีเองได้ผ่านกล่องยืนยันเตือน — หากยังมีบัตรที่ไม่หมดอายุ ระบบจะไม่อนุญาตให้ลบ

BOOKING FLOW

ขั้นตอนการจองบัตร

1
เลือกคอนเสิร์ตจากหน้าแรก กรองตามประเภท
2
เลือกวันที่แสดงรอบการแสดงได้หลายวัน
3
เลือกโซนจากผังวงแหวนราคาตามชั้นบัตร
4
เลือกที่นั่งรายตัวสถานะเรียลไทม์ทุกที่นั่ง
5
ยืนยันการจองถือที่นั่ง + นับถอยหลัง 10 นาที
6
โอนเงิน + แนบสลิปรอแอดมินอนุมัติ
7
รับตั๋ว QRจองสำเร็จ พร้อมเข้างาน

⚠ ไม่ชำระภายใน 10 นาที → สถานะคงเป็น "รอชำระเงิน" พร้อมนับถอยหลังบนหน้า ตั๋วของฉัน — ผู้ใช้ยกเลิกเองได้

SALE LIFECYCLE

รอบชีวิตการขายบัตร

DRAFT
ฉบับร่าง

สร้างใหม่ ยังไม่เปิดจอง — อยู่ในเมนู "แบบร่าง" ลบหรือแก้ไขได้ (เดโม่มีตัวอย่าง)

OPEN
เปิดขาย

ผู้ใช้เห็นและจองได้ — ระบบปิดอัตโนมัติเมื่อถึง วันสุดท้ายของการขาย (ตรวจทุก 60 วินาที)

CLOSED
ปิดขาย

ปิดชั่วคราวหรือหมดเวลา — เปิดใหม่ได้

SOLD_OUT
บัตรหมด

ทุกโซนเปิดขายหมด — ระบบตั้งสถานะอัตโนมัติ (เดโม่มีตัวอย่าง "ซิมโฟนีออฟไฟร์เวิร์คส์")

CANCELLED
ยกเลิกถาวร

ยกเลิกกลางคันเพื่อป้องกันปัญหา — แก้ไขข้อมูลไม่ได้อีก

ON-DUTY & VERIFIER

ADMIN FEATURES

ฟีเจอร์สำหรับแอดมิน (เมนูเรียงใหม่)

1 · การจองทั้งหมด

ดูการจองของลูกค้าทุกรายการ กรองตามสถานะ พร้อมรหัสตั๋วรายที่นั่ง

2 · ตรวจสอบสลิป

ดูสลิป อนุมัติ/ปฏิเสธพร้อมเหตุผล — บันทึกรหัสแอดมินผู้ตรวจและแสดงในรายการอนุมัติแล้วให้ทุกคนเห็น

3 · สถิติและข้อมูล

รายได้รวม รายได้รายโซน สถานะบัตร + Export PDF / CSV

4 · แบบร่าง

คอนที่ยังไม่เปิดขาย — แก้ไข เปิดขาย หรือลบทิ้ง

5 · สร้างคอนเสิร์ต

ปกคอนเซปต์ (16:9) · ชื่อ 2 ภาษา · หลายวันแสดง · ตั้งราคา/เปิดขายรายโซน · วันสุดท้ายขายปิดอัตโนมัติ

6 · เพิ่มแอดมิน

พื้นที่จำกัดสิทธิ์ — ต้องใส่รหัสลับทุกครั้ง (ดูสไลด์จัดการแอดมิน)

ACCOUNT SAFETY

ความปลอดภัยของบัญชีและข้อมูล

ข้อมูลตัวตนใช้ซ้ำไม่ได้

อีเมล · เบอร์โทร · เลขบัตรหน้า-หลัง — บังคับ Unique ระดับฐานข้อมูล สมัครซ้ำไม่ได้แม้พร้อมกัน ต้องลบบัญชีเดิมก่อนจึงสมัครใหม่ได้

กันลบบัญชีเมื่อมีบัตรค้าง

ยังมีบัตรคอนเสิร์ตที่ไม่หมดอายุ (งานยังไม่จัดผ่าน) → ระบบปฏิเสธการลบพร้อมบอกจำนวน — ต้องใช้บัตรหรือยกเลิกจองก่อน

ยืนยันก่อนลบถาวร

กล่องยืนยัน (Modal) แจ้งหมายเหตุสีแดงว่าลบแล้วกู้คืนไม่ได้ ต้องกดยืนยันอีกชั้น — ไม่ใช้ป๊อปอัปเบราว์เซอร์ธรรมดา

รหัสลับตรวจที่ server

การเพิ่ม/ลดแอดมินต้องส่งรหัสยืนยันมาทุกคำสั่ง — ข้ามหน้าเว็บยิง API ตรงก็โดนปฏิเสธเหมือนกัน

แยกบทบาททุกด่าน

ทุก API หลังบ้านตรวจ JWT + authorize("ADMIN") ทุกครั้ง — โทเคนของ USER เรียก API หลังบ้านไม่ได้

DATA MODEL

Zone + Seat

StaffDuty

Notification
