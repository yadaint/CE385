WEB APPLICATION PROJECT · CE385

BOOKING TICKET CONCERT

ระบบจองตั๋วคอนเสิร์ตออนไลน์ — เลือกโซน เลือกที่นั่ง ชำระเงินผ่านสลิป
และรับบัตรเข้างานพร้อม QR Code รายที่นั่ง ครบในที่เดียว

React + TypeScript · Express + Prisma + PostgreSQL · Tailwind CSS · i18n (ไทย/EN)

OVERVIEW

ภาพรวมโปรเจกต์

🎯 โจทย์

การจองบัตรคอนเสิร์ตแบบเดิมมีข้อจำกัดเรื่องผังที่นั่ง คิวยาว การยืนยันการชำระเงินไม่ชัดเจน และไม่รู้สถานะบัตรแบบเรียลไทม์

💡 โซลูชัน

เว็บแอปจองตั๋วครบวงจร — ผู้ใช้เลือกผังโซนและที่นั่งเองจากผังจริง โอนเงินพร้อมแนบสลิป แอดมินตรวจและอนุมัติ จองสำเร็จได้บัตร QR

🎫 ผลลัพธ์

บัตรเข้างานพร้อม QR รายที่นั่ง รหัสตั๋วมาตรฐาน 10 ตัว สถิติรายคอนพร้อมรายงาน PDF/CSV และรองรับสองภาษา

ทุกสถานที่ใช้ผังมาตรฐานเดียวกัน (Standard End Stage): Standing ชิดเวที → VIP → Platinum → Gold → Silver → Balcony

USER FEATURES

ฟีเจอร์สำหรับผู้ใช้

สมัครสมาชิก + ยืนยันตัวตน

ชื่อ-นามสกุล · วันเกิด · เบอร์โทร · เลขบัตรประชาชน 13 หลัก (ตรวจ checksum) · เลขหลังบัตร (Laser code) — ตรวจทั้ง client และ server

ผังโซนวงแหวนรอบเวที

Standing ชิดเวทีสุด → VIP → Platinum → Gold → Silver → Balcony พร้อม % การจองรายโซน

เลือกที่นั่งรายตัว

สถานะทุกที่นั่งเรียลไทม์: ว่าง / รอตรวจสอบ / ยืนยันแล้ว — จองได้สูงสุด 4 ที่นั่งต่อรอบ

ชำระเงิน + นับถอยหลัง

โอนเข้าบัญชีกสิกรไทย พร้อมนับถอยหลังชำระ 10 นาที และแนบสลิปเพื่อรอแอดมินตรวจสอบ

ตั๋วเข้างาน + QR รายที่นั่ง

รหัสตั๋วมาตรฐาน 10 ตัว พร้อม QR ตรวจสอบหน้างาน แสดงเมื่อสลิปได้รับอนุมัติ

สองภาษา + ลบบัญชีเอง

ไทย / English สลับได้ทันทีทุกหน้า และผู้ใช้สามารถลบบัญชีพร้อมข้อมูลการจองได้ด้วยตัวเอง

BOOKING FLOW

ขั้นตอนการจองบัตร

1
เลือกคอนเสิร์ตจากหน้าแรก กรองตามประเภท
2
เลือกวันที่แสดงรอบการแสดงได้หลายวัน
3
เลือกโซนจากผังวงแหวนราคาตามชั้นบัตร
4
เลือกที่นั่งรายตัวสถานะเรียลไทม์ทุกที่นั่ง
5
ยืนยันการจองถือที่นั่ง + นับถอยหลัง 10 นาที
6
โอนเงิน + แนบสลิปรอแอดมินอนุมัติ
7
รับตั๋ว QRจองสำเร็จ พร้อมเข้างาน

⚠ ไม่ชำระภายใน 10 นาที → สถานะคงเป็น "รอชำระเงิน" พร้อมนับถอยหลังบนหน้า ตั๋วของฉัน — ผู้ใช้ยกเลิกเองได้

TICKET CODE

รหัสตั๋วมาตรฐาน 10 ตัวอักษร — 1 ที่นั่ง = 1 บัตร

THAGD14K7X

ตัวอย่าง: Gold ที่นั่งเบอร์ 14 ของคอนไทย — จองหลายที่นั่งได้บัตรครบทุกที่นั่ง

THA / NAT

ประเภทคอนเสิร์ต — คอนไทย (THA) หรือคอนต่างประเทศ (NAT)

GD

รหัสโซนที่นั่ง 2 ตัว — เช่น GD = Gold Center

14

เลขที่นั่ง 2 ตัว (01-99) — ตามที่นั่งที่ทำการจอง

K7X

รหัสสุ่มจากระบบ 3 ตัว — กันการซ้ำ

SALE LIFECYCLE

รอบชีวิตการขายบัตร

DRAFT
ฉบับร่าง

สร้างใหม่ ยังไม่เปิดจอง — อยู่ในเมนู "แบบร่าง" ลบหรือแก้ไขได้

OPEN
เปิดขาย

ผู้ใช้เห็นและจองได้ — ระบบปิดอัตโนมัติเมื่อถึง วันสุดท้ายของการขาย (ตรวจทุก 60 วินาที)

CLOSED
ปิดขาย

ปิดชั่วคราวหรือหมดเวลา — เปิดใหม่ได้

SOLD_OUT
บัตรหมด

ทุกโซนเปิดขายหมด — ระบบตั้งสถานะอัตโนมัติ

CANCELLED
ยกเลิกถาวร

ยกเลิกกลางคันเพื่อป้องกันปัญหา — แก้ไขข้อมูลไม่ได้อีก

ADMIN FEATURES

ฟีเจอร์สำหรับแอดมิน

สถิติรายคอนเสิร์ต

เลือกคอน (แยกหมวดเปิดขาย/ปิดขาย) → รายได้รวม รายได้รายโซน สถานะบัตรทั้งหมด + ตารางรายโซน

จัดการคอนเสิร์ต (เรียลไทม์)

ผังโซนวงแหวน + สถานะทุกที่นั่ง ว่าง/รอตรวจสอบ/ยืนยันแล้ว — รีเฟรชอัตโนมัติทุก 10 วินาที

รายการตรวจสอบสลิป

ดูสลิป อนุมัติ/ปฏิเสธพร้อมเหตุผล — บันทึกชื่อแอดมินผู้ตรวจทุกรายการ

Export PDF + CSV

ส่งออกรายงานสถิติและรายการจองเป็นเอกสาร (PDF แบ่งหน้าอัตโนมัติ / CSV UTF-8 เปิดใน Excel)

สร้าง + แก้ไข + แบบร่าง

ปกคอนเซปต์ (16:9) · ชื่อ 2 ภาษา · วันสุดท้ายขาย (ปิดอัตโนมัติ) · ยกเลิกการขายกลางคัน · ลบแบบร่างได้

DATA MODEL

โครงสร้างฐานข้อมูล (Prisma + PostgreSQL)

User

บัญชี + ข้อมูลยืนยันตัวตน (ชื่อ / เบอร์ / เลขบัตรหน้า-หลัง / วันเกิด) — ลบบัญชีเองได้

Concert

คอนเสิร์ต + ชื่อ 2 ภาษา + ปกคอนเซปต์ + saleEndDate (ปิดขายอัตโนมัติ)

Venue + VenueZone

ผังโซน FIX ประจำสถานที่ — ทุกสถานที่ใช้ผังมาตรฐานเดียวกัน

Zone + Seat

โซนขายบัตรรายคอน + ที่นั่งรายตัว (isAvailable อัปเดตแบบ transaction)

Booking + BookingSeat

การจองถือที่นั่ง + รหัสตั๋วรายที่นั่ง (SERIALIZABLE transaction + retry)

Payment

สลิป + สถานะ + ผู้ตรวจ (reviewedBy) + เวลาตรวจ

Notification

แจ้งเตือนบัตรหมดรายโซน/ทั้งคอน อัตโนมัติ

ทุกความสัมพันธ์กำหนด onDelete: Cascade — ลบคอน/ลบบัญชี แล้วข้อมูลลูกถูกจัดการอัตโนมัติ

SUMMARY

สรุปโปรเจกต์

  • ระบบจองตั๋วครบวงจร ตั้งแต่เลือกที่นั่งจนได้บัตร QR เข้างาน
  • ผังโซนมาตรฐานสากล เหมือนกันทุกสถานที่ ทั้งหน้าสร้างและหน้าจอง
  • รหัสตั๋วมาตรฐาน 10 ตัว รายที่นั่ง พร้อม QR สแกนเข้างาน
  • ปิดขายอัตโนมัติตามวันสุดท้าย + ยกเลิกการขายกลางคัน + ลบแบบร่าง
  • สถิติรายคอน 3 มุมมอง ส่งออกรายงาน PDF / CSV ได้
  • สองภาษา ไทย/English — ผู้ใช้ลบบัญชีตัวเองได้
